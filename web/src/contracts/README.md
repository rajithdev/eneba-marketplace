# API response examples

One example response per catalog endpoint, generated by the backend from the
seeded catalog. They are the contract between the API and this frontend:

- the backend test `CatalogContractTest` fails if the API stops returning
  exactly these responses;
- the frontend's TypeScript types are checked against these files, and its
  tests use them as mock data.

Do not edit them by hand. After an intended API change, regenerate them and
review the diff:

```bash
make contracts
```

Each file holds the request it answers and the response. Database ids are not
part of the contract: every `id` is replaced by its position in its list.
